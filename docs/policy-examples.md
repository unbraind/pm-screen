# Screening protocols declared before acquisition

These protocols are proposed by the implementing recorder. Maintainer approval and independent reviewer judgments have not been supplied; no such approval or independence is claimed.

1. **Open issues:** all open issues (pull requests excluded) from the public pm-csv, pm-beads and pm-brief repositories at acquisition. Include a recorded release-workflow failure, witnessed by an Actions run link and failure description. Exclude a report whose actual subject is only package behavior rather than a release workflow. Missing or inaccessible bodies remain unknown.
2. **Public tracker frame:** the first 20 item IDs in lexical order in each complete, all-status snapshot of pm-csv, pm-beads, pm-ops and pm-brief. Include records that explicitly cite an SDK gap or missing SDK capability in title, description, body or comments. Exclude records solely about a dependency/release version bump with no SDK capability gap. This is an 80-item declared frame, not an exhaustive corpus or estimate of prevalence. Submitted summaries must distinguish a gap citation from ordinary SDK usage.
3. **Search hits:** the full returned hit set for `repo:unbraind/pm-csv repo:unbraind/pm-beads repo:unbraind/pm-brief is:issue SDK`. Include an issue reporting loss, omission or overwrite of context in import, reconciliation or bounded output. Exclude release-only failures or unsupported feature requests. A search-result set is a declared frame; engine recall and index completeness are unknown.

Each assessment supplies every criterion, a reason and a digest-pinned source reference. A witnessed failed inclusion or witnessed exclusion excludes; unavailable evidence alone is uncertain. Two slots are used only for explicitly attributed passes. Two passes from the same recorder do not establish independent review.

The independent mechanical oracle is a truth table on submitted vectors plus integer accounting. It must not import the production reducer. Synthetic alias, unavailable-source, disagreement and source-change controls are evaluated separately from public judgments.
